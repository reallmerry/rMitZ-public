# Установка Drones

## Требования

- **Сервер:** Paper (или форк — Purpur и т.п.) версии **1.21.x**
- **Java:** 21

## Зависимости (плагины)

| Плагин | Обязателен | Зачем |
|---|---|---|
| **CommandAPI** | да | команды `/drone` |
| **packetevents** | да | управление FPV (WASD), дальний рендер дронов |
| **ModelEngine** (R4.x) | нет, но рекомендуется | 3D-модели дронов |

Без ModelEngine плагин работает — дроны просто рисуются моделью предмета вместо
3D-модели. CommandAPI и packetevents нужны обязательно.

---

## Установка по шагам

1. **Поставьте зависимости** в папку `plugins/`:
   - `CommandAPI`
   - `packetevents`
   - (опционально) `ModelEngine` версии R4.x

2. **Закиньте `Drones-1.0.jar`** в папку `plugins/`.

3. **Установите модели и ресурсы** (входят в комплект при покупке).
   В архиве из папки `install/` уже лежат готовые библиотеки моделей и настройки —
   ничего настраивать вручную не нужно:
   - распакуйте архив на сервер согласно вложенной структуре папок
     (блюпринты моделей попадают в `plugins/ModelEngine/blueprints/`,
     ресурспак — туда, откуда вы раздаёте его игрокам);
   - если ModelEngine уже запущен — выполните `/meg reload`.

4. **Подключите ресурспак** игрокам. Он нужен для звуков двигателей, взрыва и
   прицела FPV. Способы на выбор:
   - пропишите его как `resource-pack` в `server.properties`, либо
   - раздавайте через ваш менеджер ресурспаков, либо
   - игроки ставят его вручную в `resourcepacks`.
   Готовый ресурспак — в том же архиве из `install/`.

5. **Перезапустите сервер.** При первом запуске плагин создаст
   `plugins/Drones/drone.yml` с настройками по умолчанию.

6. **Проверьте:**
   ```
   /drone give shahed
   ```
   — в инвентаре появится комплект. ПКМ по блоку — развернуть, затем
   `/drone launch <id> <координаты>`.

## Настройка

Файл `plugins/Drones/drone.yml` — все параметры по каждому типу дрона
(модель, масштаб, звуки, сила взрыва, радиус сбития, ModelEngine-блюпринт и т.д.)
и общие настройки (лимит дронов, дальность видимости, поведение чанков, радиус
РЭБ). Файл подробно прокомментирован.

После правки конфига примените изменения:
```
/drone reload
```

### Если слышно наложение звука двигателя
У каждого типа есть параметр `sound-loop-ticks` — это период перезапуска звука
мотора. Поставьте его равным **длине вашего ogg-файла двигателя в тиках минус ~2**
(20 тиков = 1 секунда). Например, звук длиной 4.3 секунды → `sound-loop-ticks: 84`.

## Частые вопросы

**Дрон виден только дымом, самой модели нет.**
Проверьте, что установлен ModelEngine и блюпринты из архива лежат в
`plugins/ModelEngine/blueprints/`, после чего `/meg reload`. Без блюпринта дрон
рисуется моделью предмета — нужен подключённый ресурспак.

**Нет звука двигателя/взрыва.**
Не подключён ресурспак со звуками (шаг 4).

**WASD на FPV не работает.**
Не установлен или не запустился packetevents.

**Команды `/drone` не появляются.**
Не установлен CommandAPI.
